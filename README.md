# IWP Models — Macro Investment OS

A personal investment research and decision management system that aggregates research from 14 macro/market analyst sources, scores a three-horizon regime stack, gates trade entries via hard rules, and journals every decision.

---

## Architecture

```
investment-os/
├── config/
│   ├── sources.yaml          # 14 source definitions with weights & metadata
│   ├── brand.py              # Color palette for reports
│   └── logo.png              # IWP brand logo
├── database/
│   └── migrations/           # PostgreSQL schema (run in order 001–010)
├── scripts/
│   ├── vault_watcher.py      # Daemon: watches Obsidian vault, ingests notes
│   ├── inbox_processor.py    # Processes Clippings/ — MD, PDF, and image files
│   ├── image_analyzer.py     # Claude vision analysis of chart images
│   ├── regime_scanner.py     # Three-horizon regime stack scorer
│   ├── decision_gate.py      # Trade entry gate — hard/soft rule checker
│   ├── trigger_monitor.py    # Daemon: monitors open positions for invalidation
│   ├── generate_reports.py   # HTML report generator (regime memo, dashboard, models)
│   ├── analytics_engine.py   # Comprehensive portfolio analytics
│   ├── import_model_history.py # Import IWP model allocation history
│   ├── test_connection.py    # Verify all system dependencies
│   ├── new_device_setup.sh   # One-command setup on a new machine
│   └── pull_latest.sh        # Pull latest code + update dependencies
├── obsidian-templates/       # Obsidian Templater templates
├── reports/                  # Generated HTML reports (gitignored)
├── .env.example              # Template for credentials
└── requirements.txt          # Python dependencies
```

## Quick Start

### New device
```bash
curl -s https://raw.githubusercontent.com/NeoDogeCapital/investment-os/main/scripts/new_device_setup.sh | bash
```

### Existing install
```bash
# Load environment
iwp

# Process new Obsidian clippings
python scripts/inbox_processor.py

# Score current regime
python scripts/regime_scanner.py

# Generate reports
python scripts/generate_reports.py

# Verify a trade
python scripts/decision_gate.py \
  --ticker SPY --direction long --allocation 0.02 \
  --thesis "..." --invalidation "..."
```

## Regime System

Three-horizon stack scored from research notes:

| Horizon | Lookback | Key Sources |
|---------|----------|-------------|
| Short-Term | 7 days | SpotGamma, LaDuc, emerging signals |
| Medium-Term | 30 days | Hedgeye, 42 Macro, Mike Green |
| Long-Term | 90 days | Howell, Gromen, Milton Berg |

**Tier eligibility** (max allocation ladder step):
- All three RISK_ON → Tier 5 (ADD RISK)
- Long + Medium RISK_ON → Tier 3 (SELECTIVE ADD)
- Long RISK_ON only → Tier 2 (MAINTAIN)
- Long RISK_OFF → Tier 0 (NO NEW POSITIONS)

---

## Model Rules (Hard — enforced at DB level)

- Max allocation per position: **12%**
- Min initiation size: **2%**
- Allocation ladder: **2% → 4% → 7% → 10% → 12%** (no skipping)
- Every trade requires a **locked thesis**
- Every trade requires **documented invalidation conditions**
